# The Lavish Restaurant

Premium responsive restaurant website for The Lavish Restaurant, Jyothinagar, Karimnagar, Telangana.

## Features
- Luxury dark/gold responsive design
- Mobile navigation
- Hero and restaurant introduction
- Signature menu showcase
- Restaurant experience highlights
- Reservation/contact call-to-action
- Google Maps directions
- 24-hour opening information
- Scroll reveal interactions

## Run locally
Open `index.html` in a browser, or serve the directory with any static web server.

## Deployment
The site is static and can be deployed directly to Vercel, Netlify or GitHub Pages.

> Menu items shown are presentation placeholders until the restaurant's official current menu, prices, phone/WhatsApp and approved photos are supplied.
